# EduInsight — Powering Public Transparency in Education Infrastructure

EduInsight adalah platform berbasis web yang mengolah dan memvisualisasikan data resmi pemerintah untuk memantau ketimpangan infrastruktur digital serta fasilitas dasar sekolah antardaerah di Indonesia guna mendukung pengambilan keputusan berbasis data (*Data-Driven Decision Support*).

---

## 🛠️ Tech Stack

- **Frontend Framework:** React.js (via Vite)
- **Styling & UI:** Tailwind CSS v4
- **Interactive Map:** Leaflet.js / React-Leaflet (GeoJSON 38 Provinsi Indonesia)
- **Data Visualization:** Chart.js / Recharts
- **Icons:** Lucide React
- **Data Source:** Satu Data Indonesia (Katalog Kemendikdasmen 2023)
